# 工资计算器 · Wage Calculator

挂在 DeepSeek Harness 界面右下角的一块工资看板。填好月薪、每月工作天数、上下班时间与午休时段，它每 2 秒结算一次「今天已经赚了多少钱」，午休期间停摆不计薪。

零依赖、无构建、不联网，配置只存在本地。

## 解决的问题

上班时间模糊，钱也模糊。这块板子把「今天截止现在赚了多少」实时摆在你面前：上班前是 0，上班中按净工时随结算周期上涨，下班后封顶为日薪，午休不涨。

点右上角 ✕ 收起后，看板缩成右下角一颗小胶囊，继续显示实时金额；点胶囊即可重新展开。

## 计算口径

```
日薪    = 月薪 / 每月工作天数
净工时  = (下班 − 上班) − 午休时长
时薪    = 日薪 / 净工时
秒涨    = 时薪 / 3600，每 2 秒结算一次显示刷新
今日已赚 = 日薪 × (已过计薪时长 / 净工时)
```

| 此刻位置 | 显示 |
|---|---|
| 早于上班时间 | `¥0.00`，状态「还没上班」，倒计时 |
| 工作时段内 | 从上班起按秒累计，午休期间保持不动 |
| 晚于下班时间 | 封顶 `日薪`，状态「今天收工了」 |

- 午休可选：留空即无午休，整段连续计薪。
- 支持跨午夜班次（下班早于上班，如夜班 22:00–06:00）。
- 金额两位小数**截断**显示，不四舍五入。
- 时间按本机本地时区计算，不联网对时。

## 安装

它是一个自包含的 DSH client 插件包（bundle 形态）：**零依赖、无需构建**，整个目录拷过去就能用。

### 给别人（分发）

把这个目录压缩后发给对方即可，例如：

```bash
zip -r wage-calculator-0.1.0.zip wage-calculator
```

包里只需要这些文件，不含 `node_modules`，也不含任何本机路径。

### 对方怎么装

把压缩包解压到任意位置，然后在自己的 DeepSeek Harness 里装：

```
plugin_manager → action: install_bundle → target: <解压后的 wage-calculator 目录>
```

装完刷新页面（桌面端退出应用再打开最稳），右下角就会出现看板。

### 装在自己机器上（开发用）

开发时建议用符号链接装，改源码后重开应用即生效、不用重装：

```bash
ln -s /path/to/wage-calculator ~/.dsh/profiles/desktop/node_modules/wage-calculator
```

## 自检

```bash
node tools/selfcheck.mjs
```

自检会从 `client.js` 的纯函数区抽取真实代码，逐秒验证包含午休剔除与跨午夜班次在内的计算口径，并核对中英文文案键一致。

## 已知限制

- **没有全局右上角状态栏**：DSH 只在打开具体会话页时才提供顶栏槽位，所以收起后的胶囊固定在右下角（`shell.overlay`，全局稳定）。
- 设置通过浏览器本地存储保存；若在不同标签/窗口间发现设置没有延续，属于宿主存储隔离，不是计算问题。
