# 给朋友的安装说明

> 这段可以直接复制转发。朋友只需要 DeepSeek Harness 桌面版，不用装 Node、不用命令行。

---

## 工资计算器 · 安装方式

一个挂在 DeepSeek Harness 右下角的小看板：填月薪、每月工作天数、上下班和午休时间，它实时显示「今天已经赚了多少钱」，午休不计薪。
零依赖、不联网、配置只存本地。

仓库地址：
https://github.com/EddyLee1010/wage-calculator

---

### 方式一：让 AI 帮你装（最简单，推荐）

在 DeepSeek Harness 里新建一个对话，**把下面这句话原样发给它**：

```
帮我安装这个 DSH 插件：
https://github.com/EddyLee1010/wage-calculator
用 plugin_manager 的 install_bundle，target 填 EddyLee1010/wage-calculator
```

它装完会告诉你结果。**装完退出应用再重新打开**（或按 ⌘R 刷新），右下角就会出现看板。

---

### 方式二：自己在界面里装

1. 打开 **设置 → 插件**（Settings → Plugins）
2. 找到安装插件的入口，装 `EddyLee1010/wage-calculator`
3. 装完**退出应用重新打开**，右下角出现看板

---

### 方式三：命令行

如果你已经在用 `dsh` 命令：

```bash
dsh plugin --profile web add github:EddyLee1010/wage-calculator
```

把 `web` 换成你实际使用的 profile 名（桌面版一般是 `desktop`）。装完**重启 dsh**。

---

## 第一次用怎么设置

装好重开之后，右下角会出现一个看板，让你填：

| 项目 | 说明 | 例子 |
|---|---|---|
| 月薪 | 税前/税后随你，只要口径一致 | 12000 |
| 每月工作天数 | 一般 21～22 | 22 |
| 上班时间 | 24 小时制 | 09:00 |
| 下班时间 | 早于上班表示跨午夜班次 | 18:00 |
| 午休 | 可以留空，留空就不扣午休 | 12:00 – 13:00 |

填完点「开始看板」，它就开始跳数字了。

---

## 怎么用

- **上班前**：显示 ¥0.00，告诉你还有多久开工
- **上班中**：从上班时间起按净工时往上跳，**午休期间不动**
- **下班后**：封顶为当天日薪，显示「今天收工了」
- **点右上角 ✕**：收成右下角一颗小胶囊，继续显示金额；**点胶囊**重新展开
- **点 ⚙**：回去改设置
- **按住标题可以拖动**看板到任何位置

---

## 如果没出现

1. **确认真的重启了应用**（不是最小化，是完全退出再打开）
2. 检查设置 → 插件里，它是不是**已启用**状态
3. 还是没有 → 把仓库地址再发给 AI，说「看看这个插件为什么没显示」

---

## 说明

- 纯前端实现，不联网、不上传任何数据，月薪只存在你自己电脑的浏览器本地存储里
- 计算口径：日薪 = 月薪 ÷ 每月工作天数；时薪 = 日薪 ÷ 净工时（已扣午休）
- 金额两位小数截断显示，不四舍五入
- 支持跨午夜班次（比如 22:00 – 06:00）
